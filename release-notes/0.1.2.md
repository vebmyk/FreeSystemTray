Portable build for Windows 10 (tested on 22H2, build 19045). Unzip anywhere and run `FreeSystemTray.exe`. See the README for usage.

Two downloads:

- `FreeSystemTray-0.1.2-win-x64.zip` (about 70 MB): the .NET runtime is inside, nothing to install.
- `FreeSystemTray-0.1.2-win-x64-framework-dependent.zip` (small): needs the [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) (x64) installed.

## Changes since 0.1.1

- New: a small framework-dependent download for machines that already have the .NET 10 Desktop Runtime.
- `tools/Publish.ps1` builds both versions; `-Only SelfContained` or `-Only FrameworkDependent` builds one.
